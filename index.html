About Me

Turning Ideas Into Reliable Software Solutions

I'm Ahmed Rady, a Computer Science graduate and Backend-Focused Software Engineer passionate about designing and developing reliable, scalable, and secure web applications.

My primary expertise lies in C# and ASP.NET Core Web API, where I focus on building RESTful APIs, implementing authentication and authorization, and designing maintainable backend architectures using Clean Architecture and CQRS.

I have hands-on experience working with SQL Server, Entity Framework Core, LINQ, and MongoDB, along with implementing JWT authentication, ASP.NET Core Identity, and role-based access control.

Through academic and personal projects, I've gained practical experience transforming requirements into functional applications, integrating APIs with external services, and building complete backend solutions.

I'm also expanding my frontend development skills with Angular and TypeScript to strengthen my full-stack capabilities. I enjoy solving technical problems, learning new technologies, writing clean code, and continuously improving my software engineering skills.

My goal is to contribute to impactful projects, collaborate with talented developers, and build software that delivers real value.
